# Visual Validation

The legacy files `desktop-1440.png`, `tablet-768.png` and `mobile-390.png` are
local-only screenshots of a superseded implementation. They are explicitly
ignored and are not Sprint 1 evidence.

Fresh acceptance evidence must be captured from the corrected PyTorch-backed
application using distinct names:

- `pytorch-desktop-1440.png`;
- `pytorch-tablet-768.png`;
- `pytorch-mobile-390.png`.

The pass must also record console, network, keyboard, horizontal-overflow and
reduced-motion results.
