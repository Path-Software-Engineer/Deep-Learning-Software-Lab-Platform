# Week 10 Exploration

## Questions

- How can the 2D representation stay readable without claiming semantics?
- Which interactions need keyboard equivalents?
- How should the third module remain visually coherent with the first two?

## Decision

Preserve Axon's dark scientific shell, evidence cards and explicit boundary
language. Use a native SVG plot with buttons for equivalent point selection,
visible focus, responsive layouts and reduced-motion support. Record the shared
visual system in `.stitch/DESIGN.md`.
