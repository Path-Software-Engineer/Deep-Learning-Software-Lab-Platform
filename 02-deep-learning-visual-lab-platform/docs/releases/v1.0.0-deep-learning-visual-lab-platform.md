# Deep Learning Visual Lab Platform v1.0.0

## Overview

This release completes Axon, a three-module educational software platform for
inspecting registered PyTorch evidence through FastAPI and Next.js.

The final Sprint adds an Autoencoder Latent Space Demo while preserving the
Neural Network Explainer and CNN Feature Map Viewer as independent bounded
contexts.

## What is included

### Neural Network Explainer

- deterministic 2–4–1 XOR MLP;
- weights, biases, preactivations and activations;
- prediction, sample loss and registered training history;
- keyboard-operable neural trace.

### CNN Feature Map Viewer

- official 900-image Fashion-MNIST sprite with verified SHA-256;
- registered ten-class CNN and held-out evaluation;
- bounded temporary PNG/JPEG inference;
- controlled PyTorch hooks for two published layers;
- up to twelve channel maps with raw activation statistics.

### Autoencoder Latent Space Demo

- convolutional autoencoder with a native 2D bottleneck;
- original/reconstruction comparison with service-calculated MSE and MAE;
- 100 registered latent reference points;
- nearest-point inspection;
- decoder-backed interpolation between two registered points;
- explicit scientific and product limitations.

## Platform engineering

- three independent PyTorch bounded contexts;
- typed Pydantic resources and versioned OpenAPI;
- five Autoencoder API operations;
- shared, alignment-stable three-module shell without redundant section routes;
- loading, connected, failure and Retry states;
- responsive CSS Modules with reduced-motion and focus rules;
- multi-stage/slim non-root Docker images;
- health-aware Docker Compose topology;
- controlled local start/stop scripts with PID and port tracking;
- Stitch-compatible design system extracted from the final frontend.

## Known limitations

- the source is a controlled 900-image subset, not the full Fashion-MNIST
  benchmark;
- the 2D bottleneck deliberately sacrifices reconstruction capacity;
- latent distance is specific to the registered checkpoint and is not
  universal semantic similarity;
- smooth interpolation does not demonstrate understanding or causality;
- no module is production ready;
- Docker image build remained blocked because Docker Desktop was not running
  and the managed session could not access its profile lock;
- responsive browser captures remained blocked by the browser security policy;
  no workaround, mockup or substituted evidence was used.

## Local execution

```powershell
.\scripts\start-local.ps1
```

For the production frontend build:

```powershell
.\scripts\start-local.ps1 -Production
```

Stop the recorded processes:

```powershell
.\scripts\stop-local.ps1
```

Run the complete repository gate:

```powershell
.\scripts\run-quality-gate.ps1
```
